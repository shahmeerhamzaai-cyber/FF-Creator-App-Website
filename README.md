# FF Creator App Website

A responsive static HTML/CSS/JavaScript download website.

## Files

- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — mobile menu, FAQ accordion and current year

## Add your real application

Create:

`downloads/FF-Creator-App-2.0.exe`

or change the download button in `index.html` to your real GitHub Release URL.

## Publish with GitHub Pages

1. Create a GitHub repository.
2. Upload the website files.
3. Make sure `index.html` is in the publishing root.
4. Open repository Settings → Pages.
5. Select the branch/folder you want to publish.
6. Save and wait for the site to deploy.

GitHub Pages is designed for static HTML/CSS/JavaScript sites.
